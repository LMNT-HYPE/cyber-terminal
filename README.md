# Sales Overview — Power BI Project

This repository now contains a starter Power BI Project (PBIP) scaffold for a fictional sales overview.

## Files

- `Sales-Overview.pbip` — project entry point
- `Sales-Overview.Report/definition.pbir` — report definition linked to the local semantic model
- `Sales-Overview.SemanticModel/definition.pbism` — semantic model project metadata
- `data/sales.csv` — fictional sample sales data

## Next step

Open `Sales-Overview.pbip` in Power BI Desktop. This is a starter scaffold, not a finished dashboard: import `data/sales.csv` into the semantic model, define relationships/measures, then add report pages and visuals in Power BI Desktop. No real business data was supplied, so the CSV is synthetic.
